# best-flight-game-20261126-0057 - Starter Entry

This is the starter entry for the best-flight-game-20261126-0057 competition.

## Program
The entry program is at `starter/main.ts`. It generates flight game data and writes it to `/output/flight.json`.

## How It Works
1. Run `node main.ts` (or `MAKEFUN_OUTPUT_DIR=out node main.ts` locally)
2. The program writes `flight.json` to the output directory
3. The data includes aircraft stats, mission info, and gameplay metrics
4. Submit the repository and transcripts to make.fun

## Determinism
The program should produce identical output on repeated runs. Use Math.seedrandom() or a fixed seed if needed.

## Scoring
Entries are scored on:
- Aircraft performance (40%)
- Mission completion (30%)  
- Gameplay score (30%)
